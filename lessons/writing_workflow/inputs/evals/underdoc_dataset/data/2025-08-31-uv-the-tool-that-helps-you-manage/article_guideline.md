# Article Guideline

- **Working title:** Intro to a modern Python project and dependency manager.
- **Bucket:** explainers
- **Audience:** Python users in data and analytics
- **Angle:** Tool explainer: the pain it removes, how it compares to alternatives, the files it creates and a hands-on example.

## Section intents

1. Open with the common dependency and environment frustrations.
2. Say what the tool is, who makes it and what it replaces.
3. Compare it with the usual alternatives on a few dimensions.
4. Explain the project files it relies on and the environment handling.
5. Relate the benefits to data work and show a worked example on his repo.
6. Close with how to get started and an invitation to share preferences.
