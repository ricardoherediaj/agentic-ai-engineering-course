# Article Guideline

- **Working title:** Turning a football dashboard notebook into a package plus a reusable agent skill.
- **Bucket:** builds
- **Audience:** football analytics practitioners and aspiring analysts and developers building with agents
- **Angle:** Revisit an older tutorial repo, explain what changed, and show how packaging knowledge as a skill lets an agent run the whole workflow.

## Section intents

1. Recap the original notebook and why it deserved an upgrade a year later.
2. State the single capability the skill offers and what the user gets out of it.
3. Explain the data sources and how they are combined.
4. Describe the new package layout and why it is structured that way.
5. Explain what the skill bundles and how an agent uses it from a plain request.
6. Describe the build process, the human review step and one bug it surfaced, then outline next steps.
