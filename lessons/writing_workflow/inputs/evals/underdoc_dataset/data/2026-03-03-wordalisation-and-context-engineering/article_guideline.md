# Article Guideline

- **Working title:** Fixing flat, spreadsheet-like LLM output in the football RAG prompt.
- **Bucket:** builds
- **Audience:** data and AI practitioners building LLM applications
- **Angle:** Diagnose why a technically correct pipeline produced lifeless text, then show two prompt-side changes and the principle that links them.

## Section intents

1. Describe the symptom: accurate numbers repeated back with no real analysis, and why the model was not at fault.
2. Introduce the technique borrowed from a football-AI researcher and what it changes about the model input.
3. Show a before and after of the prompt and of the generated text.
4. Cover a second change inspired by a course lesson on how context is formatted and ordered, with the reasoning behind each choice.
5. Show the resulting prompt layout.
6. Connect both changes under one principle and summarise the data flow end to end.
