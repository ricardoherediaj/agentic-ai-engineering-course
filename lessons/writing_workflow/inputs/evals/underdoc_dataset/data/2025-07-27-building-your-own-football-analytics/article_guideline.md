# Article Guideline

- **Working title:** A reusable match-dashboard template built from free event data.
- **Bucket:** builds
- **Audience:** football analytics practitioners and aspiring analysts
- **Angle:** Build walkthrough: what a match dashboard is, the data, each plot's purpose, development notes and next steps.

## Section intents

1. Define the dashboard and who benefits from it.
2. State the toolset and the selection of plots.
3. Explain the data sources and coordinate issues.
4. Go through each plot and what it shows.
5. Share development iterations and the roadmap, then link the repo.
