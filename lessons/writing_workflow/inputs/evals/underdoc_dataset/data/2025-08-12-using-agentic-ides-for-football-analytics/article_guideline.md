# Article Guideline

- **Working title:** A practical guide to coding football projects with agentic IDEs.
- **Bucket:** explainers
- **Audience:** football analytics practitioners and aspiring analysts who code and want to use AI coding tools
- **Angle:** Introduce the idea of AI-assisted coding, name the real pain points, offer a repeatable project setup, ground it in two small football tasks and compare two tools.

## Section intents

1. Frame how the way code gets written has shifted, with a credible reference.
2. Define agentic IDEs in plain terms and what they typically offer.
3. List the practical difficulties he met when using them day to day.
4. Propose a lightweight, repeatable project setup that works across tools.
5. Illustrate it with two football tasks, including what went wrong and how the context fixed it.
6. Give guidance for getting reliable output, then compare the two tools on strengths and annoyances.
